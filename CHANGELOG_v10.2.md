# Tank Revival: Orzeł Overdrive v10.2.0-dev

## Theater Consequence Engine, Sector Doctrines & Branching War State

- Added a persistent ten-sector consequence layer that remembers the doctrine produced by the previous sector instead of dropping strategic choices when the short v10.1 order window closes.
- Real v10.1 ASSAULT / INTERDICTION / FORTIFY choices have priority; sectors without an explicit order resolve from the existing v8.4 campaign-memory result and v10.0 command momentum.
- BREAKTHROUGH carries offensive initiative into the opening four rounds of the next sector through bounded real HE support against priority combat threats.
- SUPPLY STARVED carries interdiction forward through real AP strikes against command/logistics infrastructure, with a tiny one-time relief reward only when no infrastructure exists.
- PREPARED DEFENSE carries fortification forward through bounded player/Orzełek sustain using the existing Health and War Bond authorities.
- Added hard-capped theater initiative (-3..+3), per-sector branch history, boss-safe scheduling and a compact battlefield briefing.
- Added an exact packaged-Windows smoke probe covering all ten sector mappings, consequence windows, branch selection, initiative caps and v8.4/v10.0/v10.1 integration.

No public release is produced by this development milestone. Qualification requires the dedicated v10.2 Windows gate plus the normal development Windows regression build before ROADMAP completion.
