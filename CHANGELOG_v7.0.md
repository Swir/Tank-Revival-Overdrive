# v7.0.0-rc1 — Public Demo 2 & Final Player Experience Reforge

## Player experience
- Added a dedicated Demo 2 presentation layer that removes the legacy full-screen first-run wall of text from the normal player flow.
- Added short contextual coaching prompts for rounds 1–10 covering movement, firing, aiming, ammunition, Orzełek defense, supply tanks, HUD density, threat priority, War Bonds and coaching controls.
- Coaching prompts auto-hide after a bounded interval and can be disabled with F2.
- Demo 2 patches stale pre-demo identity in the menu and overlays current candidate/version identity on pause and end-state presentation.
- Combat readability now starts in battlefield-first Minimal mode while preserving the existing F1 Minimal/Focus/Standard cycle and critical-warning logic.

## Demo 2 qualification
- Added `Demo2CISmokeProbe` for exact packaged-runtime verification.
- Added a dedicated non-development Windows x64 Demo 2 candidate workflow.
- Candidate ZIP includes the existing exact-commit manifest and build metadata generated by `BuildDemoCandidate`.
- Candidate ZIP receives an SHA-256 checksum before any runtime test.
- A fresh Windows runner boots the exact packaged EXE using `-demo2-ci-smoke`.
- The same exact packaged candidate must then pass the existing automated late-round 80/90/100 soak before v7.0 roadmap completion.

## Authority / safety
- No combat damage, penetration, movement, AI, Health, Projectile, campaign or economy authority is replaced.
- `main` remains untouched until the candidate has passed qualification and is intentionally reviewed/merged.
